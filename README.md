# DailyAlgorithmPractice

用 C++ 记录算法练习，从初学者基础逐步过渡到大学生 CCF CSP 备赛。题目全部选自洛谷，每题保存实现和简短复盘。

## 从这里开始

[打开 30 道洛谷题与 30 天学习安排](CSP-30天题库.md)

建议按编号学习，已经熟练的题可以跳过。普通日暂按约 2 小时安排，两次综合练习另留连续 4 小时；基础不稳就先复习，不为追题量跳过关键知识。

| 阶段 | 题目编号 | 学习内容 |
| --- | --- | --- |
| 初学者基础 | 01–08 | 输入输出、判断、循环、数组、排序和去重 |
| 排序应用与模拟 | 09–14 | 结构体、字符串、函数、规则实现 |
| 常用算法 | 15–23 | 前缀和、二分、区间合并、背包和 map |
| 长题提升 | 24 | 网络连接：地址解析与操作状态 |
| 综合限时练习 | 25–30 | 两组洛谷自组练习，练选题、实现和检查 |

A+B 和排序已有代码，题库标为“已收录，待自测”。综合分组用于大学生 CCF CSP 备赛训练，不是官方真题模拟，也不把练习分数换算为认证分数。

## 目录结构

- Easy/YYYY-MM-DD-ProblemID-Title/：语法、数组与简单模拟。
- Medium/YYYY-MM-DD-ProblemID-Title/：常用算法与综合模拟。
- Hard/YYYY-MM-DD-ProblemID-Title/：当前较难的长题和综合练习。
- CSP-30天题库.md：全部题目链接、学习重点、状态和日程。

目录难度按自己的掌握程度记录，不代表洛谷官方难度。

## 每题怎么复盘

先独立尝试，再记录算法、复杂度、错误及反例。看过提示的题标记“待重做”，隔 2–3 天重新实现。完成进度只记录实际练习结果。
